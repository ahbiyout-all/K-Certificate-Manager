# K-인증서 매니저 사용자 매뉴얼 (User Guide)

본 매뉴얼은 K-인증서 매니저의 주요 기능과 사용 절차를 상세히 안내합니다.

---

## 1. 개요 및 인증서 체계
K-인증서 매니저는 대한민국 공공 및 금융 환경에서 쓰이는 인증서를 지원합니다:
- **GPKI (정부공동부문)**: 중앙부처, 지자체, 공공기관 공무원 전용 인증서
- **EPKI (교육기관부문)**: 교육부, 시도교육청, 초·중·고·대학교 교직원 전용 인증서
- **NPKI (금융/공동인증서)**: 시중은행 및 금융결제원 발급 범용/은행용 공동인증서

인증서는 반드시 공개키 파일인 `signCert.der`와 비밀키 파일인 `signPri.key`가 한 쌍으로 구성되어야 정상적인 전자서명이 가능합니다.

---

## 2. 주요 기능 사용법

### 2.1 인증서 자동 탐색 및 목록 확인
- 프로그램 시작 시 로컬 디스크 및 사용자 프로필의 표준 경로(`C:\Users\{Username}\AppData\LocalLow\...`)를 자동으로 검색합니다.
- **명확한 시각적 상태 배지 및 색상 구분 (v1.4.4)**:
  - **`유효함` (Emerald Green)**: 싱그러운 초록 배지(`✓ 유효함`)로 정상 서명 가능한 인증서를 식별.
  - **`만료 임박` (Amber Orange)**: 오렌지 배지(`⚠️ 만료 임박 D-N`)로 30일 이내 갱신 대상 표기.
  - **`만료됨` (Rose Red)**: 선명한 빨강 펄스 배지(`✕ 만료됨`)로 폐기/정리 대상 식별.
- **상태별 퀵 필터 탭 (v1.4.4)**: 목록 상단 툴바에서 `전체`, `유효함`, `만료 임박`, `만료됨` 탭을 클릭하여 원하는 상태의 인증서만 즉시 추려볼 수 있습니다.
- 인증서 이름을 클릭하면 발급자(CA), 시리얼 번호, 키 알고리즘, 세부 경로를 상단 상태 배너와 함께 한눈에 파악할 수 있습니다.

### 2.2 대상 디스크 지정 팝업창, 자가 복사 금지 및 파일 충돌 해결 (v1.4.5)
1. **복사 목적지 디스크 지정 전용 팝업창 (`TargetDrivePickerModal`)**:
   - 백업할 인증서를 체크하고 `[선택 복사]`를 누르거나 `[전체 일괄 백업]`을 클릭하면, 대상 드라이브를 직관적으로 선택하는 전용 팝업창이 나타납니다.
   - **물리 디스크 및 USB 전용 감지**: PC 내 시디롬(CD/DVD/ISO), 가상디스크(VHD/RAMDisk), 구글 드라이브/원드라이브/드롭박스/레이드라이브 등 클라우드 마운트 드라이브는 목록에서 제외되며, 실제 연결된 물리 디스크 및 USB만 안전하게 감지됩니다.
   - **오복사 방지 안내**: 이동식 USB가 연결되어 있지 않은 경우 `💡 이동식 USB 메모리가 연결되지 않았습니다` 안내 배너가 점등되어 C: 드라이브로의 무의식적 오복사를 사전에 방지합니다.
2. **동일 디스크 및 USB 내 자가 복사(Self-Copy) 금지 규칙**:
   - 선택한 인증서가 이미 보관되어 있는 동일 드라이브(예: `E:` USB ➔ `E:` USB, 또는 `C:` 내장 ➔ `C:` 내장)를 복사 목적지로 선택하는 것을 원천 차단합니다.
   - 대상 드라이브 카드에 `🚫 자가 복사 금지` 잠금 배지가 부착되며, 전체 선택 항목이 대상 드라이브에 존재하는 경우 [복사 시작] 버튼이 안전하게 비활성화됩니다.
3. **목적지 동일 파일 충돌 해결 옵션 선택**:
   - **`⚡ 스마트 덮어쓰기 (overwrite)`**: 목적지에 동일 인증서/파일 존재 시 유효기간을 비교하여 최신 파일로 자동 교체.
   - **`📁 이름 변경 보존 (archive_old / rename)`**: 기존 원본 파일을 삭제하지 않고, 백업본 폴더/파일명 뒤에 타임스탬프(`_복사본_20260930`)를 붙여 원본과 복사본을 모두 안전하게 보존.
   - **`⏭️ 건너뛰기 (skip)`**: 동일한 인증서 바이너리가 목적지에 이미 존재할 경우 복사를 스킵.
4. 백업 완료 후 파일 크기와 SHA-256 해시 검증이 수행되어 데이터 손상 여부를 검증합니다.

### 2.3 만료된 인증서 및 다른 사용자 인증서 정리
- **만료된 인증서 삭제**: 목록 상단의 `만료 인증서 삭제` 버튼을 누르면 기한이 만료된 인증서만 필터링되어 안전하게 정리할 수 있습니다.
- **다른 사용자 인증서 정리**: 공용 PC에서 퇴직자나 이전 사용자의 인증서를 골라 삭제할 수 있습니다.
- 삭제 전 확인 체크박스를 통과해야만 삭제가 진행됩니다.

### 2.4 휴지통 및 실행 취소(Undo)
- **실행 취소**: 인증서를 삭제하면 화면 우측 상단에 알림과 함께 `[실행 취소]` 버튼이 8.5초간 노출되며, 클릭 즉시 복원됩니다.
- **휴지통 열기**: 사이드바 또는 상단 헤더의 `휴지통` 아이콘을 클릭하여 보관 중인 삭제 인증서를 확인하고 원하는 항목만 선택 복원하거나 전체 복원할 수 있습니다.

### 2.5 실시간 USB 마운트 감지 및 수동 제어 중심 연동 (v1.4.2 개선)
- **조용한 백그라운드 자동 인식**: 새로운 이동식 USB를 본체에 꽂으면, 사용자의 현재 작업을 방해하는 강제 팝업 없이 백그라운드에서 즉시 드라이브 목록과 인증서 폴더(`NPKI`, `GPKI`, `EPKI`)를 자동 갱신합니다.
- **사용자 주도 원클릭 실행**: 원하는 시점에 하단 또는 상단의 **`[📥 USB ➔ PC 넣기]`** 또는 **`[💾 선택/전체 USB 백업]`** 버튼을 클릭하여 안전하게 작업을 시작할 수 있습니다.
- **친절한 미연결 안내**: USB가 연결되지 않은 상태에서 백업이나 가져오기를 누르면, 시스템 오류 대신 USB 연결 방법과 해결 팁이 담긴 친절한 안내 창이 표시됩니다.

### 2.6 연결된 백업 드라이브 현황: 기본 표시 및 고급 표시 전환 (v1.4.1 개선)
- **표시 모드 원클릭 상호 전환**:
  - 드라이브 현황 바 우측 상단의 **[📋 기본 표시]** / **[⚙️ 고급 표시 (상세)]** 세그먼트 버튼을 클릭하여 원하는 뷰로 즉시 전환할 수 있습니다.
  - 선택한 뷰 모드는 브라우저 로컬 저장소에 안전하게 기억되어 다음 접속 시에도 동일한 상태가 유지됩니다.
- **기본 표시 (Basic View)**:
  - 복잡한 하드웨어 식별 번호나 기술 정보를 덜어내고, 일반 사용자가 가장 필요로 하는 **용량 게이지 바(여유 용량 프로그레스 바)**와 **원클릭 핵심 액션(인증서 보유 시 '컴퓨터로 복사', 미보유 시 '이 드라이브로 백업')**을 직관적으로 제공합니다.
- **고급 표시 (Advanced View)**:
  - 시스템 관리자 및 파워유저를 위한 모드로, **하드웨어 고유 VSN(Volume Serial Number) 식별자 칩 및 1클릭 복사**, **파일시스템(FAT32/exFAT/NTFS)**, **버스 인터페이스(USB/NVMe)**, **WMI 정밀 진단 연계**, **컴퓨터로 복사 + 백업 듀얼 액션 버튼**을 모두 제공합니다.
- **최상단 우선 배치 & 필터링**:
  - 연결된 외장 SSD, USB 드라이브 중 인증서가 들어 있는 드라이브가 목록 상단에 자동으로 정렬됩니다.
  - **[인증서 보유만]** 토글을 켜면 빈 드라이브를 제외하고 실제 인증서가 든 드라이브만 즉시 추려볼 수 있습니다.

### 2.7 USB 쓰기/읽기 장애 대비 최대 3회 자동 재시도 (v1.4.0 신규)
- USB 이동식 디스크 특성상 발생하는 일시적인 연결 지연, 쓰기 권한 락, 접촉 불량 오류 발생 시 즉시 실패하지 않습니다.
- 500ms ➔ 1000ms ➔ 1500ms 지수 백오프(Exponential Backoff)를 거치며 **최대 3회까지 자동으로 재시도**를 수행하여 전송 신뢰성을 대폭 향상했습니다.
- 모든 재시도 시도와 성공 여부는 `작업 로그` 모달에서 실시간으로 확인할 수 있습니다.

### 2.8 데스크톱 대시보드 퀵 전송 카드 양방향 전환 (v1.4.0 신규)
- 대시보드 메인 상단의 퀵 전송 카드에서 `🖥️ PC ➔ 💾 USB 백업`과 `💾 USB ➔ 🖥️ 내 PC 복사` 모드를 탭 버튼으로 손쉽게 전환할 수 있습니다.
- 작업 방향에 따라 추천 드라이브와 액션 버튼이 자동 전환되어 직관적으로 인증서를 관리할 수 있습니다.

### 2.9 USB에서 내 컴퓨터로 가져오기 (반대 경로 복사)
- **목적**: USB 이동식 메모리나 백업 디스크에 저장되어 있는 인증서를 현재 사용 중인 PC의 인증서 보관함(`AppData\LocalLow`)으로 복원·가져옵니다.
- **실행 방법**:
  1. 상단 안내 배너의 `[USB에서 PC로 넣기]` 또는 헤더/사이드바의 `[USB ➔ PC 넣기]` 버튼을 클릭합니다.
  2. **가져올 소스 선택**:
     - **드라이브 자동 검색**: PC에 꽂힌 USB 드라이브를 지정하여 `NPKI`, `GPKI`, `EPKI` 폴더를 즉시 스캔합니다.
     - **직접 폴더 선택**: 브라우저 디렉터리 선택 창으로 USB 내 인증서 폴더를 직접 지정합니다.
     - **백업 ZIP 파일**: 이전에 압축 백업해 둔 `.zip` 파일을 드래그하여 업로드합니다.
  3. 가져올 인증서를 선택하고, 대상 PC의 사용자 계정명(기본값: `Admin`)과 덮어쓰기 여부를 확인합니다.
  4. `[PC로 복사 시작]` 버튼을 누르면 로컬 경로(`C:\Users\{User}\AppData\LocalLow\NPKI` 등)로 안전하게 배치되며 메인 목록에 즉시 등록됩니다.

### 2.10 프로그램 설치 및 실행 (Inno Setup 폴더 풀림 Unpacked Multi-File & 슬림 정규 설치)
- **설치 관리자 실행**: `kcert-manager-v1.4.5-setup.exe`를 실행합니다.
- **한국어 / 영어 2종 라이선스 지원**: 설치 마법사 언어 선택에 따라 한국어(`LICENSE_KR.txt`) 또는 영어(`LICENSE_EN.txt`) 라이선스 전문이 표시됩니다.
- **폴더 풀림(Unpacked Multi-File) 슬림 설치 구조**:
  - 기본 설치 경로(`C:\Program Files (x86)\K-Certificate Manager` 또는 사용자 지정 폴더)에 단일 캡슐화 방식이 아닌, 프로그램 구동에 필요한 정규 구성 요소가 원본 트리 그대로 **중복 없이 개별 파일 단위로 완전히 풀려서 설치**됩니다:
    - `{app}\KCertManager.exe` : C# WPF 데스크톱 풀버전 실행 파일 (단일 1벌 배치, 중복 패킹 원천 제거)
    - `{app}\KCertManager-Lite.exe` : 초경량 WPF 에디션 (단일 1벌 배치)
    - `{app}\KCert.Core.dll` : 4대 코어 모듈 독립 라이브러리
    - `{app}\run-web.cmd` : 웹 브라우저 실행 스크립트 (`127.0.0.1` 로컬 보안 격리 서버 구동 및 브라우저 열기)
    - `{app}\LICENSE.txt`, `LICENSE_KR.txt`, `LICENSE_EN.txt` : 한·영 통합 및 한국어/영어 공식 라이선스
    - `{app}\dist\` : 모든 정적 웹 에셋(HTML, CSS, JS)이 원본 폴더 구조 그대로 개별 추출
    - `{app}\docs\` : 사용자 가이드 및 기술 명세서 등 필수 마크다운 매뉴얼 파일 개별 보관
- **설치 완료 후 원클릭 옵션**:
  - 설치 마법사 종료 시 **[K-인증서 매니저 C# WPF 데스크톱 실행]** 또는 **[설치 폴더 열기 (Unpacked Multi-File)]** 옵션을 선택할 수 있어 풀린 개별 파일들을 직접 윈도우 탐색기에서 확인할 수 있습니다.
- **시작 메뉴 바로가기 제공**:
  - `K-인증서 매니저 (C# WPF 데스크톱)`
  - `K-인증서 매니저 (C# WPF 경량 에디션)`
  - `K-인증서 매니저 (웹 버전)`
  - `설치 폴더 열기 (Unpacked Multi-File)` (탐색기로 바로 열기)
  - `소프트웨어 라이선스 - 한국어 (License KR)` / `Software License - English (License EN)`
  - `사용자 가이드 (User Guide)` 및 `버전 릴리스 패치노트 (Patch Notes)`
- **완전 삭제(제거)**:
  - 제어판의 `프로그램 추가/제거` 또는 시작 메뉴 내 `K-인증서 매니저 제거`를 통해 폴더 풀림으로 전개된 모든 개별 파일과 로그를 찌꺼기 파일 없이 100% 완전하게 언인스톨합니다.

### 2.11 모던 일체형 타이틀바 & 4대 테마 고대비 시스템 (v1.4.5)
- **모던 일체형 타이틀바 (`WindowChrome`)**:
  - C# WPF 데스크톱 앱 상단의 흰색 Windows 기본 창 제목줄을 제거하고, 깔끔한 3D 메탈릭 K-방패 로고와 창 제어 버튼(`─`, `□`/`❐`, `✕`)을 일체형으로 통합했습니다.
  - 상단 헤더에 복잡하게 있던 중복 버전 뱃지를 제거하여 넓고 쾌적한 화면을 제공하며, 현재 버전 정보는 **창 좌측 하단 상태바(`v1.4.5 | ...`)**에서 상시 확인할 수 있습니다.
  - 상단 헤더 바의 빈 공간을 마우스로 드래그하여 창을 이동하거나, 더블클릭하여 전체 화면 최대화/복원을 수행할 수 있습니다.
- **4가지 맞춤형 컬러 테마 및 WCAG 고대비 시안성 보장**:
  - **다크 (Dark)** / **회색 (Gray)** / **화이트 (White)** / **베이지 (Beige)**
  - 전 테마에서 글자와 배경 간 명암비를 WCAG AA/AAA 수준으로 대폭 개선하여 어두운 모달이나 경고 배너에서도 글자가 뭉개지지 않고 선명하게 보입니다.
  - 상단 헤더의 테마 스위치 버튼을 클릭하면 타이틀바, 사이드바, 본문 카드, 하단 상태 표시줄까지 전체 색상이 즉시 하나로 통일됩니다.

### 2.12 C# WPF 네이티브 데스크탑 앱 및 한국어 친화적 오류 안내 (v1.4.5)
- **데스크탑 배포 에디션 안내 및 실행 정보**:
  - 💽 **공식 설치 마법사 에디션 (`kcert-manager-v1.4.5-setup.exe`)**: 시작메뉴/바탕화면 바로가기 등록, 프로그램 추가/제거 지원 정식 인스톨러.
  - 📦 **무설치 포터블 압축 패키지 (`KCertManager-v1.4.5-WPF-Desktop.zip`)**: 압축 해제 시 버전이 명시된 2개의 실행 파일만 담겨 있어 혼란 없이 즉시 사용 가능:
    - **`KCertManager_v1.4.5.exe`**: .NET 10 / .NET 8 런타임 내장 독립 실행형 바이너리 (별도 설치 없이 즉시 실행).
    - **`KCertManager-Lite_v1.4.5.exe`**: 초경량 프레임워크 종속 실행 바이너리 (~6MB).
- **사용자 친화적 한국어 오류 해결 안내**:
  - 권한 부족, USB 쓰기 금지 잠금, 다른 보안 프로그램의 인증서 파일 점유 등 오류 발생 시 어려운 영문 코드 대신 원인과 단계별 해결 방법을 친절한 한국어로 안내합니다.

### 2.13 GitHub Releases 실시간 자동/수동 업데이트 확인
- **최신 버전 실시간 감지 및 수동 확인**:
  - 앱 실행 시 자동으로 최신 버전을 감지할 뿐만 아니라, 상단 헤더 또는 사이드바의 **`[🔄 수동 업데이트 확인]`** / **`[✨ 업데이트 확인]`** 버튼을 클릭하여 언제든지 실시간으로 새 버전을 확인할 수 있습니다.
- **원클릭 업데이트 안내 모달**:
  - 최신 버전인 경우: "모든 보안 패치와 최신 규격이 완벽하게 적용되어 있습니다" 안내.
  - 신규 버전이 있는 경우: 내 현재 버전과 최신 버전 비교, 패치노트 요약 및 GitHub 최신 데스크톱 실행 파일 다운로드 링크가 즉시 제공됩니다.

### 2.14 복사 완료 시 시각적 행 깜빡임 및 Web Audio API 화음 알림음 (v1.4.3)
- **목록 내 복사 행 하이라이트 깜빡임**:
  - 인증서 디스크 백업이나 USB ➔ 컴퓨터 복사가 완료되면, `CertificateList` 내 대상 행들이 에메랄드 빛으로 2회 부드럽게 반짝이는 CSS 키프레임 애니메이션이 적용됩니다.
  - 복사된 인증서 우측에 `✨ 복사 완료` 배지가 함께 점등되어 복사 대상을 한눈에 식별할 수 있습니다.
- **맑고 청량한 Web Audio API 완료 화음**:
  - 외부 음원 파일 로딩 없이 브라우저 내장 Web Audio API를 활용하여 3단계 상승 하모닉 차임(`Eb5 ➔ G5 ➔ C6`)을 즉시 재생합니다.
  - Windows WPF 데스크톱 앱에서도 시스템 사운드가 동기화되어 복사 종료를 명확히 청각적으로 안내합니다.

### 2.15 3D 메탈릭 K-Shield 방패 아이콘 & 투명 바탕화면 패키징 (v1.4.3 신규)
- **최신 3D 메탈릭 K-방패 엠블럼**:
  - 좌측 코발트 블루와 우측 실버 크롬 분할 방패 및 3D 입체 치즐 K 로고가 적용된 공식 보안 엠블럼을 전면 채택했습니다.
- **100% 완전 투명 배경 (Alpha = 0)**:
  - 바탕화면 바로 가기 아이콘 외곽의 사각형 박스를 완전히 제거하여, 사용자의 바탕화면 배경 그림이나 주변 아이콘을 일체 가리지 않습니다.
  - 방패 엠블럼 실루엣 자체가 캔버스 경계를 꽉 채워(96% 점유) 바탕화면에서 시원하고 선명하게 표시됩니다.
