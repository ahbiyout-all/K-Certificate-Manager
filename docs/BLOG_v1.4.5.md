### [본문]
안녕하세요! 대한민국 공무원/공공기관용 행정전자서명 인증서(**GPKI / EPKI**)와 일반 은행 및 금융권에서 사용하는 공동인증서(**NPKI**)를 가장 직관적이고 안전하게 관리할 수 있는 오픈소스 보안 도구, **K-인증서 매니저(K-Certificate Manager) v1.4.5** 버전이 정식 릴리스되었습니다!

인증서 복사를 위해 복잡한 AppData나 Windows 폴더를 헤매셨나요? 이제 **K-인증서 매니저**가 스마트하게 시스템을 탐색하여 단 한 번의 클릭만으로 USB 드라이브 및 로컬 디스크 간 상호 일괄 복사와 정밀한 백업 관리를 지원합니다. 

이번 v1.4.5 업데이트에서는 **정밀 고대비 시인성 개편**, **대상 디스크 전용 선택창 탑재**, **자가 복사 금지 보호 규칙**, **WPF 팝업 전체 dynamic 테마 연동** 등 사용자 가독성과 안정성을 극대화한 기능들이 추가되었습니다.

---

### [업데이트]
#### ✨ v1.4.5 주요 업데이트 및 개선 사항
1. **대상 디스크 지정 전용 팝업창 (`TargetDrivePickerModal`) 탑재**
   - 일괄 백업, 복사 시작 클릭 시 대상 USB나 이동식 디스크를 사전에 안전하게 확인 및 선택할 수 있는 직관적인 드라이브 선택 전용 창을 마련하였습니다. C:드라이브 등으로의 의도치 않은 오복사를 원천 차단합니다.
2. **동일 디스크/USB 자가 복사(Self-Copy) 금지 보호막 적용**
   - 현재 보관 중인 드라이브와 동일한 경로(예: E: USB ➔ E: USB)로 무의미하게 파일이 덮어씌워져 데이터가 손상되거나 충돌하는 상황을 자동 검증하여 완벽히 차단하고 안내 배너를 출력합니다.
3. **글자 시인성 및 고대비(WCAG AA/AAA) 전면 개편**
   - 회색, 화이트, 베이지 등 라이트 테마 설정 시 일부 글자가 흐릿하게 보이거나 배경색과 동화되어 가독성이 떨어지던 현상을 완전히 해결했습니다. 전 테마에서 진하고 선명한 고대비 컬러를 완벽 제공합니다.
4. **WPF 모든 팝업 다이얼로그(창) 동적 테마 완벽 연동**
   - 프로그램 내의 모든 서브 창(`About`, `로그`, `백업 이력`, `인증서 상세`, `만료 정리`, `보안 가이드`, `휴지통`, `USB 전송` 등)에 실시간 DynamicResource 바인딩을 적용하여 어떠한 테마 상황에서도 아름답고 일관된 다크/라이트 화면을 보여줍니다.
5. **실제 물리 디스크 & USB 목록화 엔진 최적화**
   - 구글 드라이브, 원드라이브, CD-ROM, 가상 RAM 디스크 등 데이터 오기록 우려가 있는 스토리지를 완벽 배제하고 오직 컴퓨터 내부의 실제 SSD/HDD 및 연결된 외장 USB 메모리만 선별 탐색합니다.
6. **목록 양방향 정렬 기능 지원 (WPF & Web)**
   - 보관함 테이블의 '구분', '저장 위치', '인증서 명칭' 등의 열 헤더를 클릭하여 오름차순/내림차순 정렬이 유연하게 작동하도록 MVVM 및 React 테이블 구조를 개선하였습니다.

### [전체 업데이트]
K-인증서 매니저 프로젝트의 런칭(v1.0.0)부터 최신 정식 버전(v1.4.5)까지의 전체 개발 역사 및 혁신 히스토리입니다.

* **🚀 v1.4.5 (2026-09-30)**
  * **버전 동적 동기화**: `package.json` 및 패치노트 파이프라인 연동으로 빌드 스크립트 실행 시 버전 정보 일괄 자동 동기화 적용 (`push_to_github.bat`, `build.bat` 내 수동 버전 하드코딩 완전 제거).
  * **대상 디스크 전용 팝업 모달 (`TargetDrivePickerModal`)**: 일괄 복사 클릭 시 원본과 대상을 미리 확인하여 오동작 및 안전 구역 외 디스크 복사를 사전 예방하는 전용 창 도입.
  * **자가 복사(Self-Copy) 금지 보호 시스템**: 동일 드라이브 내에서 원본과 대상이 일치할 때 발생하는 무의미한 덮어쓰기 및 데이터 손상을 검증하여 배너 표시 및 연산 차단 (`CertTransferEngine.cs`, `backupService.ts`).
  * **전 테마 글자 시인성 WCAG AA/AAA 개편**: 회색, 화이트, 베이지 등 밝은 테마 사용 시 글자가 잘 보이지 않던 문제를 명확한 슬레이트/차콜 톤으로 정밀 보정하여 가독성 완전 교정.
  * **WPF 모든 다이얼로그 동적 테마 연동**: 모든 서브 창(`About`, `로그`, `만료 정리`, `휴지통` 등)에 실시간 DynamicResource를 보완 적용하여 일관된 인터페이스 연출.
  * **목록 양방향 정렬 구현**: WPF 데스크톱 `DataGrid` 및 Web 에디션에서 '구분', '저장 위치', '인증서 명칭' 컬럼 헤더 클릭 시 오름차순/내림차순 정렬 연동.
  * **배치 파일 인코딩 수정**: Windows CMD와의 개행 호환성을 맞추기 위해 모든 스크립트를 CRLF로 전수 변환 및 `.gitattributes` 영구 고정.

* **🚀 v1.4.4 (2026-09-30)**
  * **충돌 해결 UI**: 백업 과정 중 동일 인증서 파일 충돌 시 "스마트 덮어쓰기", "이름 변경 보존(_복사본_날짜)", "건너뛰기"를 사용자가 선택할 수 있는 다기능 옵션 탑재.
  * **상태별 퀵 필터 탭**: '전체 / 유효함 / 만료 임박 / 만료됨' 퀵 탭을 추가하고 유효함(에메랄드), 만료됨(로즈 레드), 만료 임박(앰버) 배지로 색상 체계 직관화.
  * **물리 스토리지 선별 기능**: CD-ROM, 가상 드라이브 및 클라우드 동기화 드라이브(구글 드라이브, 원드라이브, 레이드라이브 등)를 드라이브 스캔 목록에서 원천 필터링.

* **🚀 v1.4.3 (2026-09-30)**
  * **명칭 미지정 구분 체계 고도화**: 소유자명 정보가 누락된 경우 발급처에 따라 `GPKI(명칭 미지정)`, `NPKI(명칭 미지정)` 등으로 분기 표시하도록 정합성 강화.
  * **오인식 방어**: 자정 23:59:59 유효 만료 기준을 엄격 적용하여 당일 사용 가능한 인증서가 만료 대상으로 오인되지 않도록 차단.
  * **휴지통 일괄 복원 기능**: Web 및 WPF 격리 보관함(Trash Vault) 내 '전체 선택/해제' 버튼과 함께 원클릭 일괄 복원 탑재.
  * **경로 텍스트 잘림 방지**: 보관 경로 텍스트 래핑 및 📋 전체 경로 복사 단축 버튼 추가.
  * **3D 메탈릭 K-Shield 전수 교체**: 투명 배경 알파채널(Alpha=0)이 보장되어 지저분한 사각 프레임이 없는 입체 엠블럼 `app.ico` 탑재.
  * **3계층 자동 업데이트 감지**: 최신 릴리스 정보, 릴리스 리스트, Git 태그 순차 추적 및 캐시 우회형 실시간 API 연계.
  * **복사 성공 애니메이션 및 음향**: 백업 완료 시 대상 행이 에메랄드로 깜빡이는 `rowCopiedFlash` CSS 효과와 Web Audio API 기반 오실레이터 3단계 합성 알림음 제공.
