공식 정식 배포 릴리스 · v1.8.0 MINOR

🛡️ K-인증서 매니저 (K-Certificate Manager) v1.8.0

순수 창작 독립 DLL(KCert.Core / KCert.Crypto) 탑재 · 상단 헤더 가로바 스크롤러 · 전역 고대비 툴팁 시스템

대한민국 공무원·교직원 행정전자서명 인증서(GPKI, EPKI)와 금융 공동인증서(NPKI)를 안전하게 관리하는 오픈소스 데스크톱 보안 유틸리티 'K-인증서 매니저 v1.8.0' 정식 버전이 출시되었습니다.

이번 v1.8.0 버전은 Semantic Versioning 3단계 분리 원칙에 입각한 대규모 기능 승격(MINOR)으로, 외부 3rd-party 의존성이 전혀 없는 순수 창작 독립 C# 코어 DLL 2종(KCert.Core.dll, KCert.Crypto.dll)을 분리 탑재하였습니다. 또한 상단 메뉴 툴바의 편의성을 극대화한 '가로바 스크롤러(Horizontal ScrollBar)' 및 마우스 휠 네비게이션, 다크 테마를 포함한 4대 테마 전반에서 글자가 선명하게 보이는 '전역 고대비 툴팁 시스템'이 공식 적용되었습니다.

✨ v1.8.0 핵심 신규 기능 및 주요 개선

  • 🧩 순수 창작 독립 C# 코어 & 암호화 DLL 2종 구축:
    대한민국 공인인증서 X.509 v3 규격, ASN.1/DER 파서, OID 분류, USB 감시, 안전 격리 휴지통 엔진(KCert.Core.dll) 및 KISA 표준 SEED-128 암호화, PKCS#8 개인키 복호화, VID 신원확인 엔진(KCert.Crypto.dll)의 완전 모듈화.
  • ↔️ 상단 헤더 가로바 스크롤(Horizontal ScrollBar) & 마우스 휠 연동:
    상단 헤더 높이를 64px로 최적화하고 상시 가로 스크롤바 표출. 툴바 위에서 마우스 휠 조작 시 좌우 가로 스크롤이 부드럽게 작동하며, 윈도우 드래그와의 간섭을 완벽 분리.
  • 💬 4대 테마 전역 고대비 툴팁(ToolTip) 시스템 탑재:
    다크 테마에서 흰색 배경에 흰색 글자가 겹치던 시인성 결함을 완벽히 해결. 다크/회색/화이트/베이지 전 테마에서 WCAG AAA 12:1+ 고대비를 만족하는 다크 플로팅 카드 + 화이트 텍스트 적용.
  • 📏 Semantic Versioning 3단계(MAJOR.MINOR.PATCH) 관리 체계 확립:
    변경 규모별 3단계 의사결정 매트릭스(Decision Tree) 및 8대 핵심 파일 동기화 체크리스트 표준화.
  • 🎚️ 헤더 실시간 볼륨 슬라이더 & WPF SettingsDialog.xaml 완비:
    원클릭 음소거 토글, 볼륨 조절 슬라이더, 성공 알림음(SuccessChime) 테스트 및 로컬 영구 설정 보존.
