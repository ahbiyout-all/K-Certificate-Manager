🛡️ K-인증서 매니저 (K-Certificate Manager) v1.7.1

만료 인증서 정리-휴지통 수량 100% 동기화 개선 & 성공 알림음 볼륨 조절 업데이트

대한민국 공무원·교직원 행정전자서명 인증서(GPKI, EPKI)와 금융 공동인증서(NPKI)를 안전하게 관리하는 오픈소스 데스크톱 보안 유틸리티 'K-인증서 매니저 v1.7.1' 정식 버전이 출시되었습니다.

이번 v1.7.1 버전에서는 만료 인증서 일괄 정리 시 삭제된 인증서 수량(예: 22건)과 안전 격리 휴지통 수량이 정확히 1:1로 일치하도록 동기화 매니페스트 엔진을 전면 고도화하였으며, 휴지통 보관 시 발급기관명과 유효기간이 완벽하게 보존됩니다. 또한 성공 알림음(SuccessChime) ON/OFF 및 볼륨 조절 슬라이더, 인증서 목록 세로 구분선 및 여백 밀도 컨트롤이 추가되었습니다.

✨ v1.7.1 핵심 신규 기능 및 주요 개선

  • 🗑️ 만료 인증서 안전 정리 시 삭제 수량과 안전 격리 휴지통 수량 100% 동기화
    22개 만료 인증서 정리 시 휴지통에도 정확히 22개가 1:1로 격리 보관되도록 매니페스트(trash_manifest.json) 생성 엔진을 개선하여 수량 불일치 현상을 완전히 해결했습니다.
  • 🏷️ 휴지통 매니페스트 메타데이터 완벽 복원 및 표시
    격리 보관소 열람 시 발급기관명(금융결제원, 행정안전부, 교육부 등), 인증서 분류, 만료일자가 원본 그대로 선명하게 출력되어 "알 수 없음" 표기 없이 상세 규격을 확인할 수 있습니다.
  • 🔔 성공 알림음(SuccessChime) ON/OFF 및 볼륨 조절 슬라이더
    환경 설정 모달(SettingsModal)에서 알림음 토글 스위치, 0%~100% 볼륨 슬라이더, 5종 음량 프리셋, 미리듣기 테스트를 지원하여 사무실이나 정숙한 환경에서도 편리하게 이용할 수 있습니다.
  • 📏 인증서 보관함 세로 구분선 및 여백 밀도 조절
    데이터 셀 간 세로선(border-r) 적용 및 [좌우 여백: 좁게 | 보통 | 넓게] 3단계 프리셋을 제공하여 대량의 인증서를 가독성 높게 열람할 수 있습니다.
  • 🔍 인증서 명칭·경로·상태 컬럼 최소 폭(30px) 자유 조절 및 공식 기관명 표기
    유연한 마우스 드래그 리사이징을 지원하여 최소 30px까지 자유롭게 폭을 줄일 수 있으며, 대한민국 주요 CA 공식 명칭 뱃지를 연동했습니다.
  • 🛡️ 보안 영구 삭제 증적 감사 로그 (SubjectDN 포렌식) 시스템 연동
    삭제 대상 인증서의 고유 식별자(SubjectDN), 원본 경로, SHA-256 전자지문을 영구 보존하고 1-클릭 클립보드 복사 및 감사 보고서(.log)로 내보낼 수 있습니다.
  • 🚀 GitHub Actions 워크플로 Node.js 24 Next-Gen / Node.js 22 LTS 전환
    GitHub Actions 클라우드 러너의 Node.js 20 Deprecated & EOL 공식 대응을 완료하여 안정적인 빌드 환경을 구축했습니다.
