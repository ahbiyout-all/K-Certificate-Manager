K-인증서 매니저 v2.1.0 정식 릴리스: GitHub 이동 없는 앱 내 자동 다운로드·무인 셀프 설치, 반응형 카드 그리드 & 다크 테마 통합, 쉬운 일상 표현 UI 개편

대한민국 공무원 인증서(GPKI), 교육기관 인증서(EPKI), 국방부 인증서(MPKI) 및 은행·공동 인증서(NPKI)를 내 컴퓨터(C:\)와 이동식 USB 메모리 간에 안전하게 복사·백업·이동할 수 있는 통합 인증서 관리 프로그램 K-인증서 매니저(K-Certificate Manager) v2.1.0 정식 버전이 출시되었습니다.

이번 v2.1.0에서는 별도 브라우저로 GitHub 웹사이트에 이동할 필요 없이, 업데이트 안내 창에서 [확인 (자동 다운로드 · 설치)]만 누르면 앱 내부에서 설치 패키지를 내려받아 무인 셀프 설치 및 자동 재실행까지 한 번에 완료되도록 개편했습니다. 또한 C# WPF 데스크톱과 동일한 통합 다크 테마(#0F1219), 화면 폭에 따라 카드가 자동 리플로우(Reflow)되는 CSS Grid auto-fill 반응형 인증서 카드 목록, 그리고 쉬운 일상 표현 우선 + 더보기 접이식 UI를 적용해 누구나 한눈에 인증서를 관리할 수 있습니다.

✨ 3. 주요 업데이트 (Recent Highlights)

  • 🚀 GitHub 이동 없는 앱 내 자동 다운로드 · 무인 셀프 설치 엔진 탑재 (WPF & Web):
    • C# WPF 데스크톱: 업데이트 창에서 [확인 (자동 다운로드 · 설치)] 클릭 시 브라우저 이동 없이 kcert-manager-v*-setup.exe를 직접 스트리밍 다운로드(진행률·MB 실시간 표시), PE 실행 파일(MZ/PK) 검증 후 숨김 스크립트(apply_self_update.ps1)로 무인 설치(/SILENT /SUPPRESSMSGBOXES /NORESTART /CLOSEAPPLICATIONS) 및 자동 재실행까지 원스톱 처리.
    • Web 관리 콘솔: 외부 페이지 이탈 없이 인앱 3단계(스트림 다운로드 ➔ 파일 손상 검사(SHA-256) ➔ 오프라인 캐시 갱신) 완료.
  • 🎨 WPF-Web 다크 테마 통합 & 반응형 CSS Grid auto-fill 카드 레이아웃: Web 콘솔 기본 테마를 WPF 다크 테마(#0F1219 / #1A1F2C)로 통일하고 다크·파스텔 블랙 모달 대비 결함을 완전 교정했으며, 화면 너비에 따라 카드가 자동 재배치되는 repeat(auto-fill, minmax(300px, 1fr)) 카드 뷰 및 표 보기 전환 지원.
  • 💬 전역 UI 쉬운 일상 표현 우선 + 접이식 더보기 UI 개편 (Web & WPF): 긴 경로·FAQ·복사 후 가이드를 1줄 핵심 요약 + 기본 접힘 토글(더보기 / WPF Expander)로 정리하고, 개인키, 원본 위치/저장 위치, 찾는 위치, 파일 손상 검사(SHA-256), 보안 점검 등 쉬운 표현으로 통일.
  • 🛡️ 3차 심층 전수 감사(Deep Audit) 결함 일괄 수정: WPF C:\ 드라이브 자가 복사 차단 보강(ResolveEffectiveDestinationRoot) 및 Web 폴더 선택 취소(AbortError) 불필요 재시도 제거·목록 상태 동기화 개선.
  • 🔒 암호화 보호 보관함(DPAPI / AES-256) & 60fps 유동 애니메이션 테두리 완비: 복원 매니페스트 이중 암호화 보호, 이동식 USB 전용 제한 복구, 984px 광폭 만료 정리창, 대각 무한 유동 네온 테두리 기본 탑재.
