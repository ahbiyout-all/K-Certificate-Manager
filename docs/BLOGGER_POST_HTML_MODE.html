공식 정식 배포 릴리스 · v1.7.2

🛡️ K-인증서 매니저 (K-Certificate Manager) v1.7.2

상단 헤더 가로 볼륨 슬라이더 바 & ⚙️ 환경 설정 모달 신설, C# WPF Two-Way 바인딩 최적화 릴리스
⚡ 상단 헤더 볼륨 슬라이더 ⚙️ WPF SettingsDialog 신설 💾 SettingsService 로컬 영구저장 🔒 휴지통 100% 동기화
대한민국 공무원·교직원 행정전자서명 인증서(GPKI, EPKI)와 금융 공동인증서(NPKI)를 안전하게 관리하는 오픈소스 데스크톱 보안 유틸리티 'K-인증서 매니저 v1.7.2' 정식 버전이 출시되었습니다.

이번 v1.7.2 릴리스에서는 상단 헤더 툴바에 가로 볼륨 조절 슬라이더 바를 직접 탑재하고, 돋보이는 ⚙️ [환경 설정] 버튼을 상시 노출하여 작업 중 언제든 1-클릭으로 효과음을 제어하고 환경 설정 창을 호출할 수 있습니다. 또한 Windows C# WPF 데스크톱에 전용 SettingsDialog.xaml과 SettingsService.cs 영구 저장소가 구축되어 설정 상태가 완벽하게 유지됩니다.

✨ v1.7.2 핵심 신규 기능 및 주요 개선

  • 🎚️ 상단 헤더 가로 볼륨 슬라이더 바 상시 탑재: 헤더 중앙에 원클릭 음소거/스피커 토글, 0%~100% 범위 슬라이더, 볼륨 수치(40%/OFF) 및 미리듣기(▶) 버튼 배치.
  • ⚙️ 눈에 잘 띄는 [환경 설정] 버튼 상단 헤더 상시 노출: 가로 슬라이더 바로 옆에 돋보이는 ⚙️ 환경 설정 버튼을 영구 배치하여 설정 접근성 극대화.
  • 🖥️ C# WPF 데스크톱 전용 SettingsDialog 신설: 알림음 제어, 🎵 효과음 미리듣기, 4대 테마 선택, 간편/상세 모드 전환, 시작 가이드 옵션 대화상자 탑재.
  • 💾 SettingsService 로컬 영구 저장소 연동: %LocalAppData%\KCertManager\kcert_settings.json을 통해 사용자 개인 환경설정 영구 보존.
  • 🔗 '다시 표시하지 않음' Two-Way 바인딩 확립: 체크박스 조작 시 ViewModel 및 설정 파일에 즉시 양방향 반영, XAML Spacing 제거로 CI 빌드 오류 원천 차단.
  • 🗑️ 만료 인증서 정리-안전 격리 휴지통 수량 1:1 완벽 일치 (v1.7.1 계승): 22건 일괄 정리 시 휴지통에도 정확히 22건 격리 보관되며 발급기관명/유효기간 메타데이터 보존.
