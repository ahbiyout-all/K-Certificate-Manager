K-인증서 매니저 v2.1.1 정식 릴리스: 복사 폴더 드라이브 루트 타겟팅, 비표준 정위치 복구·휴지통 격리, 중복 건너뛰기 안내 및 전수 감사 안정화

대한민국 공무원 인증서(GPKI), 교육기관 인증서(EPKI), 국방부 인증서(MPKI) 및 은행·공동 인증서(NPKI)를 내 컴퓨터(C:\)와 이동식 USB 메모리 간에 안전하게 복사·백업·이동할 수 있는 통합 인증서 관리 프로그램 K-인증서 매니저(K-Certificate Manager) v2.1.1 정식 버전이 출시되었습니다.

이번 v2.1.1 패치 릴리스는 v2.1.0의 인앱 자동 다운로드·무인 셀프 설치, WPF-Web 다크 테마 통합, CSS Grid auto-fill 반응형 카드 목록, 쉬운 일상 표현 UI를 기반으로, 실제 사용 환경에서 발생할 수 있는 경로·중복·복구 워크플로우의 세밀한 오류를 전면 보완했습니다. 특히 '복사된 폴더 열기' 시 실제 드라이브 루트(E:\NPKI\...) 정밀 연결, 비표준 위치 인증서의 정위치 복구 후 원본 즉시 안전 휴지통 격리·로그·토스트 연동, 중복 건너뛰기(skip) 0건 전용 안내, PC 표준 경로 우선 중복 판정까지 한층 단단해진 신뢰성을 제공합니다.

✨ 3. 주요 업데이트 (Recent Highlights)

  • 🏛️ Class1 기관·특수목적 인증서 구분 배지 & 사이드바 CLASS1 필터 신설: C:\GPKI\Certificate\class1, EPKI, USB class1 경로에서 개인키(.key/.pri) 쌍 보유 인증서만 선별 표시(Root/CA/CRL 및 중복 _env.cer 제외)하고, CLASS1 · 공무원(GPKI) · CLASS1 · 교육(EPKI) · CLASS1 · 기관 배지 및 사이드바 CLASS1 필터·키워드 검색을 지원합니다.
  • 📁 복사 완료 폴더 실제 드라이브 루트(E:\NPKI\...) 탐색기 타겟팅 보강: OperationCompleteModal · BackupModal · OperationCompleteDialog에서 '복사된 폴더 열기' 클릭 시 드라이브 문자 뒤 누락 백슬래시(\)와 하위 경로 조합을 정규화해 실제 드라이브 루트를 정확히 열어주며, Web 환경에서도 안전 브리지·폴더 피커·클립보드 폴백을 지원합니다.
  • 🧹 비표준 경로 정위치 복구 마법사·안전 휴지통 격리 워크플로우 완성: handleRepairFolders · DiagnosticsRepairDialog · CertIntegrityDoctor(specificDerPath 정밀 진단)에서 표준 경로 복사 완료 후 중복 ID를 정리해 원본을 안전 휴지통(SafetyTrash)으로 즉시 격리하고 활동 로그·성공 토스트를 기록하며, 동일 경로 자기덮어쓰기 IOException을 사전 차단합니다.
  • 🛡️ 중복 건너뛰기(skip) 0건 가드 및 Web/WPF 5차 심층 전수 감사 안정화:
    • Web 관리 콘솔: skip 옵션으로 실제 복사 0건일 때 중복 건너뛰기 완료 안내 화면 표시; USB:\ 표준 경로·TradeSign(NPKI_CORP)·class1 계층 통일 및 타이머·리스너 누수 정리, localStorage/JSON 스키마·프로토타입 오염 방어 적용.
    • C# WPF 데스크톱: CI 컴파일(Regex/널 참조 경고) 해소, DispatchSafe·OnClosed·IDisposable·비동기 try/catch 수명주기 정리, SafetyTrashManager 읽기 전용 해제, KCertAntiDuplicationEngine PC 원본 우선 선정 및 FastScanPipeline 말단 \MPKI 인식 보강.
  • 🚀 인앱 자동 다운로드·무인 셀프 설치 & WPF-Web 다크 테마·반응형 카드 UI (v2.1.0 계승): 업데이트 창 [확인 (자동 다운로드 · 설치)] 원스톱 셀프 업데이트, 통합 다크 테마(#0F1219), CSS Grid auto-fill 카드 레이아웃, 쉬운 일상 표현 + 더보기 UI, DPAPI/AES-256 암호화 보호 보관함, 60fps 유동 네온 테두리를 제공합니다.
